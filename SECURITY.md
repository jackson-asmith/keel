# Security Policy

## Reporting a vulnerability

Please don't open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/jackson-asmith/keel/security/advisories/new)
("Report a vulnerability" on the Security tab). I'll acknowledge reports
within a week and keep you updated while a fix is prepared.

## Supported versions

Fixes land on `main` and in the next release. Older releases aren't patched.
